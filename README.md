`msheet` provides a framework for writing lesson sheets and exams. The package `msheet` is targeted primarily at math and physics teachers at the Rolf-Benz-Schule Nagold.

## Contents of the package

- `README.md`                 this file
- `CHANGES.md`                log of changes (history)
- `msheet.sty`				LaTeX package file (style file)
- `msheet.cls`				LaTeX class file
- `edit.png`				Picture (icon)
- `experiment.png`			Picture (icon)
- `flask.png`				Picture (icon)
- `info.png`				Picture (icon)
- `task.png`				Picture (icon)
- `teamwork.png`			Picture (icon)
- `Rolf-Benz-Schule.png`	Picture (logo)
- `msheet.pdf`				Documentation for msheet
- `msheet.tex`				Source code of the documentation (main file)
- `msheet-example.tex`		Example file for package usage
- `msheet-example.pdf`		Compiled example

## Installation

Copy the contents of the `msheet.zip` from codeberg to your local TeX file tree.

Alternatively, put the files to their respective locations within the TeX installation:

- `msheet.sty`				->  /tex/latex/msheet
- `msheet.cls`				->  /tex/latex/msheet
- `edit.png`				->  /tex/latex/msheet
- `experiment.png`			->  /tex/latex/msheet
- `flask.png`				->  /tex/latex/msheet
- `info.png`				->  /tex/latex/msheet
- `task.png`				->  /tex/latex/msheet
- `teamwork.png`			->  /tex/latex/msheet
- `Rolf-Benz-Schule.png`	->  /tex/latex/msheet
- all other files           ->  /doc/latex/msheet
